Baan Un Jai PlannerBaan Un Jai Planner

  • Hackathon prototype

Loan-readiness self-assessment that scores credit risk and suggests an action plan.

(Overview)

Live site(opens in a new tab)GitHub(opens in a new tab)

A Thai-language credit self-assessment built for the GHB Innovation Hackathon 2025. Five short steps cover income and expenses, debts, saving habits, personal details and goals; the app then scores the applicant's credit risk and turns it into an action plan for becoming loan-ready. A companion Python prototype explores an LLM planner that retrieves lending policies (BM25 + vector search), proposes Plan A/B/C, checks them with a critic model and compares debt-service-ratio scenarios.

Key featuresKey features

  1. 01Five-step assessment: income, debt, savings, profile, goals
  2. 02Credit-risk result with a personal action plan
  3. 03PDPA consent before any data entry
  4. 04Prototype RAG planner with debt-service-ratio scenarios
